# anchorHalf: built 17 September 2026, superseded the same day, never administered

`anchorAll` was replaced with `anchorHalf`, which showed 3-1 and 1-3 and asked for *half*, so that the covered box was correct and no critical configuration was rewarded.
It was then discussed and dropped within the hour, so no participant ever saw it.
The files are kept because the reasoning is worth having, not because the design is.

Why it was dropped.
An anchor asking for a proportion sets up the question *what proportion of the cookies does Bix have*, and a proportional question under discussion promotes exactly the scalar inference the study is trying to cancel.
A variant with 3-1 against 4+0 would have recovered the local-versus-global diagnostic, since the 4+0 box holds four of the eight cookies on screen and is therefore globally half, but it makes the proportional QUD sharper still.
There is also a small result worth keeping: the globally-half box is always also a locally-at-least-half box, since b = T/2 together with b < b' gives b + b' > T, so no display can separate a global reader from a lower-bounded reader of *half*.

The decision that replaced it was to stop adding controls and copy Huang, Spelke & Snedeker's Experiment 1 as closely as possible, which has no anchor at all.
